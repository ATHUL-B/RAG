# Learning notes

One note per guide Part, written in your own words after implementing it:
`NN-<topic>.md` (e.g. `04-chunking.md`). Suggested sections:

- **Concept**: what it is and why it exists, in three sentences.
- **What I built**: file paths and the key design choice.
- **What the numbers showed**: link the `experiments/LOG.md` entry.
- **Surprises / open questions**.
